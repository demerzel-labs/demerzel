# Repository history

Demerzel moved to this repository on 2026-09-04, before its public release.
The move changed every commit ID. It did not change the benchmark receipts.

## Commit IDs and benchmark receipts

Older receipts and documents can name a commit ID from before the move.
The [commit map](history-commit-map.tsv) contains one row for each earlier commit.
The first column contains the earlier ID.
The second column contains the current ID.
A short ID matches the start of the earlier ID.

Use the current ID with `git show` or `git checkout`.
The map covers all 46 benchmark receipts from before the move.
Receipt filenames, recorded IDs, and measurements remain unchanged.
The map identifies the corresponding source. It does not represent a new benchmark run.

## Pull request numbers

Pull request numbers recorded before 2026-09-04 belong to the pre-publication repository.
Those pull requests are not available here.
This repository starts its own issue and pull request numbering.
Commit messages and milestone documents keep the earlier numbers.
